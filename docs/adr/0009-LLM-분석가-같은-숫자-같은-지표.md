# ADR 0009 — LLM 분석가: 통계 모델과 같은 숫자를 주고 같은 지표로 채점한다

- 날짜: 2026-11-18
- 상태: 승인

## 배경
컨셉은 "원래 데이터 분석가에게 맡길 수준의 분석을 LLM과 통계 모델이 대신 하고, 그 분석이 실제로 맞는지 앱이 스스로 잰다"이다(CLAUDE.md 1). ADR 0008의 통계 기준선(Elo Brier 0.6021)이 생겼으니, 다음 질문은 **LLM에게 같은 정보를 주면 통계 모델보다 나은가, 그리고 나은 이유가 '추론'인가 '기억'인가**이다.

## 선택지
### 입력
1. **특성 표의 숫자만 (채택)** — Elo 차, 최근 5경기 승점·득실·xG 차, 휴식일 차, 선발 변경 차. 통계 모델과 정보가 같아야 비교가 공정하다. 빈 값은 "not available"로 명시해 지어내지 않게 한다.
2. 숫자 + 뉴스 기사 — 가디언 기사는 LLM 가공 금지(ADR 0006). 다른 소스는 약관 확인 전.

### 모델·호출
1. **`gemini-3.5-flash-lite` 무료 티어, 경기당 1회, pydantic 스키마로 JSON 강제 (채택)** — 분당 15·하루 500회(2026-11-14 확인, 바뀔 수 있음)라 380경기를 하루에 돌릴 수 있다.
2. 상위 모델(`gemini-3.8-flash`) — 하루 20회라 한 시즌에 19일. 나중에 일부 경기로만 비교 가능.

### '기억' 통제
1. **팀 이름을 '팀 A / 팀 B'로 가린 변형을 같은 경기에 따로 묻기 (채택)** — 모델이 2024-25 실제 결과를 학습했을 수 있다. 가려도 성능이 같으면 숫자로 추론한 것이다. 비용 때문에 시즌에서 고르게 뽑은 90경기만.
2. 학습 시점 이후 시즌만 평가 — 아직 끝난 시즌이 없다(2025-26 진행 중). 시즌이 끝나면 가장 깨끗한 검증이 된다.

### 결합
1. **LLM과 Elo 확률의 단순 평균 (채택)** — 가중치를 학습하면 평가 시즌으로 맞추는 셈이라 누출 위험. 가중치 학습은 LLM 예측이 학습 시즌에도 쌓인 뒤.

## 결정
위 채택안. 코드: `app/analysis/llm_analyst.py`(입력 글 만들기·확률 다듬기는 순수 함수, 네트워크는 `ask` 하나), `predictions.py`(통계·LLM 예측을 같은 `predictions` 테이블에 (경기, 모델, 버전)으로 저장), `llm_run.py`(이미 있는 경기는 건너뛰어 끊겨도 이어서 실행 → 같은 표로 채점). 확률은 합 1로 맞추고 0은 0.02로 올린다(로그 손실 무한대 방지). 프롬프트 버전 `v1`을 결과와 함께 저장한다.

## 결과 (2026-11-18, 학습 2022·2023 → 평가 2024 시즌 380경기)

| 모델 | n | Brier ↓ | 로그 손실 ↓ | 정확도 |
|---|---|---|---|---|
| Elo 차이만 | 380 | 0.6021 | 1.0048 | 53.2% |
| LLM (v1) | 380 | 0.5938 | 0.9945 | 51.6% |
| LLM + Elo 평균 | 380 | **0.5937** | **0.9924** | 52.4% |
| LLM, 팀 이름 가림 | 54 | 0.6290 | 1.0424 | 44.4% |
| LLM, 같은 54경기 | 54 | 0.6243 | 1.0329 | 44.4% |
| Elo, 같은 54경기 | 54 | 0.6353 | 1.0440 | 44.4% |

같은 경기끼리 짝지은 Brier 차의 95% 부트스트랩 구간(`evaluate.paired_brier_diff`):
- LLM − Elo: −0.0083 [−0.0226, +0.0057] → **0을 포함. LLM이 낫다고 말할 수 없다.**
- LLM+Elo − Elo: −0.0083 [−0.0155, −0.0013] → **결합은 Elo보다 낫다** (작지만 구간이 0 아래).
- 가림 − 안 가림 (54경기): +0.0047 [−0.0097, +0.0187] → 기억 효과가 있다는 근거 없음. 다만 54경기라 구간이 넓다.

해석: LLM 단독은 Elo와 비슷하고, 둘을 섞으면 조금 낫다. LLM의 무승부 확률 평균(0.25)이 실제 비율(0.245)에 가깝고 Elo(0.20)는 무승부를 낮게 본다 — 결합의 이득은 여기서 온 것으로 추정한다(검증 안 함).

**틀릴 수 있는 것**: 가림 실험은 계획한 90경기 중 54경기에서 멈췄다(호출이 멈춰 중단, 나머지는 이어서 실행 가능). 경기당 한 번만 물어 같은 질문을 다시 하면 답이 달라질 수 있다. 같은 실행이 두 개 겹쳐 일부 경기는 두 번 묻고 나중 답으로 덮였다(프롬프트는 같음). 평가 시즌의 xG·선발 변경은 11%만 채워져 있다.
