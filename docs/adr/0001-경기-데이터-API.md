# ADR 0001 — 경기 데이터 API로 football-data.org 채택

- 날짜: 2026-11-14
- 상태: 승인

## 배경
경기 결과·순위·득점 순위를 보여줄 데이터 출처가 필요하다. 비용 0원, 비상업 포트폴리오.

## 선택지
1. **football-data.org** — 무료 키로 EPL 경기·순위·득점 순위. 응답 구조가 단순. 라인업·상세 스탯은 무료에 없음.
2. TheSportsDB — 가입 없이 시작 가능하지만 데이터 품질·갱신이 들쭉날쭉.
3. API-Football — 데이터가 가장 풍부하지만 무료는 하루 100회, 현재 시즌 제한 가능성.

## 결정
1번. v1 범위(결과·순위·기본 스탯)에 충분하고 설명하기 쉽다.

## 결과
- 호출은 `frontend/lib/football.ts` 한 곳에서만 한다. 응답은 `lib/mappers.ts`에서 우리 타입으로 바꾸므로 API를 갈아끼워도 화면 코드는 그대로다.
- 응답을 60초(경기)/300초(순위) 캐시해 호출 한도를 지킨다.
- **확인 필요**: 무료 한도(분당 10회로 알고 있음), 득점 순위의 도움(assists) 제공 여부, 엠블럼 이미지 사용 조건 — 키 발급 시 약관에서 재확인.
- 경기 상세(라인업·타임라인)가 필요해지면 이 ADR을 다시 연다.
