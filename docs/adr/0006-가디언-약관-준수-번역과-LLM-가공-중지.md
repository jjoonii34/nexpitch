# ADR 0006 — 가디언 기사는 원문 그대로 24시간만, 번역·LLM 가공은 하지 않는다

- 날짜: 2026-11-16
- 상태: 승인 (ADR 0005를 폐기한다)

## 배경
BBC RSS를 두 번째 소스로 붙이려고 약관을 읽다가 가디언 Open Platform 약관(https://www.theguardian.com/open-platform/terms-and-conditions, 2026-11-16 확인)도 확인했다. 이미 만든 번역 기능이 아래 조항에 어긋났다.
- "You will not: Edit, adapt, **translate** or otherwise alter the OP Content."
- "You will not use ... OP Content ... with any **machine learning and/or artificial intelligence technologies** to generate any data or content" — 번역뿐 아니라 태깅·요약·질문 답변도 해당.
- "delete all OP Content you hold ... at least every **24 hours**."
- 표시 조건: 전체 헤드라인·바이라인·저작권 표기 유지, 원문 링크 유지, 같은 페이지에 "Powered by The Guardian" 로고.
BBC 약관 15조도 RSS 내용을 "바꾸지 않고 그대로" 붙이는 것만 허용한다 → BBC 추가는 취소.

## 선택지
1. **약관 준수 모드로 전환** — 번역·LLM 중지, 원문 그대로 표시, 24시간 보관.
2. 가공을 허용하는 소스로 교체 — 무료이면서 LLM 가공을 허용하는 축구 뉴스 소스는 드물다. 조사 필요.
3. 그대로 둔다 — CLAUDE.md 7번(약관 위반 금지) 위반. 선택지가 아니다.

## 결정
1번을 즉시 적용한다. 2번은 별도 조사 후 다시 ADR.

## 결과
- 배치: 수집 → **24시간 정리**(`python -m app.cleanup`). 번역 단계 제거. 수집에서 다시 본 기사는 `collected_at`을 갱신해 보관을 연장하고, 24시간 넘게 안 보인 기사는 연결·번역과 함께 지운다 ("replace by re-requesting"을 이렇게 구현).
- 데이터: `article_translations`의 기존 번역 전부 삭제. 테이블과 번역 코드(`app/llm/translate.py`)는 남겨 둔다 — 가공을 허용하는 소스가 생기면 그대로 쓴다. 배치·화면에서는 쓰지 않는다.
- 화면: 제목(전문)·요약·바이라인을 고치지 않고 표시. 뉴스 페이지에 "Powered by The Guardian" 로고(가디언 배포 파일 그대로)와 저작권 표기. 검색은 영어만.
- 가디언 무료 키 한도 확정: 초당 1회, 하루 500회 (우리는 하루 40회, 구단 사이 1초 간격).
- **잃는 것**: 한국어 번역, 그리고 가디언 기사 기반의 태깅·기자 티어·질문 답변 계획. "LLM·NLP를 어디에 쓸지"는 다시 정한다 (notes 2026-11-16).
- **확인 필요**: football-data.org 약관(경기 데이터를 LLM 입력으로 써도 되는지). 약관 페이지 주소를 아직 못 찾았다.
