# ADR 0013 — 전술 특성 7개 추가, LLM에 보낸 입력을 예측과 함께 저장

- 날짜: 2026-11-19
- 상태: 승인

## 배경
4단계 결과(ADR 0010): LLM 가설 97건이 전부 Elo 차 하나만 썼다. 입력에 '어떻게 경기하는 팀인가'가 없으니 전술 가설이 나올 수 없었다. 소유자 지적: "Elo만으로는 너무 대충, 축구에는 전술적 방향성이 있다." 또 평가 하네스(4.5단계 ①)를 만들다가, 모델에 보낸 입력을 저장하지 않아 나중에 근거 문장을 대조할 수 없다는 것을 알았다(수집이 진행되면 xG 값이 바뀐다).

## 선택지
### 전술 특성
1. **팀 스탯에서 만드는 스타일 지표 + xG 공수 분리 + 포메이션 변경 (채택)** — 이미 수집 중인 데이터(ADR 0007)만 쓴다. 전부 '최근 5경기, 그 경기 전까지'의 홈 − 원정 차.
2. 포메이션끼리의 상성 — 포메이션이 13종이라 조합당 표본이 몇 경기뿐. 제외.
3. 감독 부임 후 경기 수 — 교체 사례가 적어 효과를 잴 수 없다. 제외.
4. 손으로 만드는 '선발 전력'(선수 평점 합) — 4.5단계 ④의 학습된 선수 임베딩으로 대신한다.
5. 압박 강도·수비 라인 등 — 무료 API에 없다. 공개 이벤트 데이터(Wyscout, CC BY 4.0)를 붙일 때 다시 본다.

### 평가
1. **스탯이 있는 경기만으로 시즌 안 시간순 평가 → 과거 시즌이 차면 기존 방식(시즌 분리)으로 재측정 (채택)** — 지금은 학습 시즌(2022·2023)에 전술 데이터가 0경기라 기존 표에 넣을 수 없다. 기본 채점(run·llm_run)에는 넣지 않고 `EXPERIMENTAL_FEATURES`로 분리했다.
2. 과거 시즌이 다 찰 때(12월 말)까지 기다림 — 한 달 넘게 결과가 없다.

### 입력 저장
1. **`predictions.input_text` 열 추가 (채택, Alembic 0002)** — 앞으로의 LLM 예측은 보낸 글을 그대로 저장한다. 기존 행은 NULL이고 하네스는 그때 특성 표로 대신 계산한다.
2. 저장하지 않고 한계만 기록 — v3에서 같은 오탐이 반복된다.

## 결정
- 특성(`dataset.TACTICAL_COLUMNS`): `possession_diff`, `pass_volume_diff`, `pass_accuracy_diff`, `box_shot_share_diff`(슈팅 중 박스 안 비율), `xg_for_diff`, `xg_against_diff`, `formation_change_diff`. 비율은 경기별 비율의 평균이 아니라 최근 경기를 합쳐서 낸다(슈팅이 적은 경기에 덜 흔들림).
- 모델: `tactical`(기존 6개 + 전술 7개), `elo+tactical`(Elo + 전술 7개 — 전술 특성만의 기여를 보기 위해).
- 점검 도구 `analysis/tactical_run.py`: 팀 스타일 표, 반분 안정성(팀마다 경기를 홀·짝으로 나눠 두 절반 평균의 상관), 시즌 안 시간순 평가(평가 경기 60개 미만이면 보류).

## 결과 (2026-11-19, 2024 시즌 중 팀 스탯이 있는 83경기 — 팀당 8~9경기)

반분 안정성 — 이 스탯이 우연이 아니라 팀이 일관되게 가진 성격인가:

| 스탯 | 반분 상관 |
|---|---|
| 경기당 패스 수 | 0.65 |
| 점유율 | 0.62 |
| 패스 성공률 | 0.54 |
| 박스 안 슈팅 비율 | 0.38 |
| 내준 xG | 0.33 |
| 만든 xG | 0.30 |
| 득실차 (비교용: 결과) | 0.30 |

- 점유·패스는 절반마다 4경기뿐인데도 0.6대 → **팀의 성격으로 볼 수 있다.** 결과(득실차)와 xG는 0.3 수준 — 팀당 8경기로는 잡음이 크다. 스타일 표도 상식과 맞는다(점유율 1위 맨체스터 시티 62.8%, 최하위 크리스탈 팰리스 37.0%).
- **예측에 보태는지는 아직 잴 수 없다**: 전술 특성이 채워진 경기가 71개라 평가용 절반이 60경기 미만 → 비교 보류. 11월 말 재실행.
- **틀릴 수 있는 것**: 상관은 20팀·경기 4개씩의 평균으로 낸 값이라 그 자체의 오차가 크다(구간을 내지 않았다). '성격이 있다'는 것이 '승패를 예측한다'를 뜻하지는 않는다. 점유율은 상대에 따라 달라지는데 상대 보정을 하지 않았다. 포메이션 문자열은 API 표기 그대로라 같은 전술이 다른 숫자로 적힐 수 있다.
